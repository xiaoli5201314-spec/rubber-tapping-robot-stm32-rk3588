# 架空底盘：遥控器本地驱动 D60A，MQTT 网页监视

本版本会实际输出电机 PWM。只用于底盘已稳固架空、履带完全离地的首次测试。
不用屏幕，不接切割工具。2026-10-14 设备通信恢复为 MQTT，
STM32 HTTP 直连已移除；电脑 HTTP 18080 继续提供同一套网页/API。
ESP-12F（ESP8266）负责网络，接收器 PWM 由 STM32 在本地捕获和控制电机。
软件编译/夹具测试不代表实际电机、供电或接线验证通过。

## 1. 遥控接收器接线（沿用当前接法）

| 接收器 | 自制板端子 | STM32 |
| --- | --- | --- |
| CH1 的 S | CN3-1 / RC_CH1 | PB10 |
| CH2 的 S | CN3-2 / RC_CH2 | PB11 |
| CH5 的 S | CN3-3 / RC_CH5 | PF6 |
| 电源 + | CN3-4 / 5V | 稳定 5V |
| 电源 − | CN3-5 / GND | 与 STM32 共地 |

右摇杆控制前后和转向，左摇杆不参与。CH5 已由用户设置为三档：
最上约 1000、中间约 1500、最下约 2000；前两档锁定，最下档允许解锁。
接收器使用当前 50 Hz 模拟舵机模式。
CH5 是通道编号，实际映射到哪个实体开关以用户的设置为准。

## 2. STM32 到布瑞特 BRT-HDC-D60A

按驱动器 **2×5 控制口的针脚编号和丝印** 核对，不按照片左右猜方向。
PA、PB 是驱动器的通道名称。

| 自制板 CN1 | STM32 | D60A 控制口 | 功能 |
| --- | --- | --- | --- |
| 1 / LEFT_PWM | PB6 | PA / 7 脚 | 左路 PWM |
| 2 / LEFT_IN1 | PD6 | A1 / 8 脚 | 左路方向 1 |
| 3 / LEFT_IN2 | PD7 | A2 / 9 脚 | 左路方向 2 |
| 4 / RIGHT_PWM | PB7 | PB / 2 脚 | 右路 PWM |
| 5 / RIGHT_IN1 | PE5 | B1 / 3 脚 | 右路方向 1 |
| 6 / RIGHT_IN2 | PE6 | B2 / 4 脚 | 右路方向 2 |
| 7 / GND | GND | G / 5 或 10 脚 | 控制地共地 |

D60A 控制口 **1、6 脚是驱动器 5V 输出，留空**。
STM32、接收器和 D60A 控制地连接在同一个地参考上。

| 功率端 | 连接 |
| --- | --- |
| D60A MA 两个端子 | 左侧电机的两根线 |
| D60A MB 两个端子 | 右侧电机的两根线 |
| D60A 电源 + / − | 适配底盘 24V 电机的功率电源 + / − |

24V 只接驱动器功率输入；STM32 和接收器使用板上低压供电。
驱动器允许的输入范围不等于电机允许的电压，首次连接仍核对电机铭牌。
功率输入串接匹配负载的保险和可直接切断电机供电的开关/急停。
MA、MB 与信号端不要混插，改变接线前等待电机停止并切断电源。

驱动器手册依据：项目 `选取的电机驱动器/布瑞特H桥驱动器说明书.pdf`
第 7–9 页 D60A 接口、控制说明及第 14 页真值表。

## 3. 上电与首次测试

1. 保持底盘架空。先断开 D60A 功率电源，接好控制线。首次可只接 MA 左电机，
   MB 电机线暂时断开并绝缘。不开启切割机构。
2. 开电脑 2.4GHz 热点 `YOUR_WIFI_SSID`；启动
   `upper_computer/web_link_host/启动网页联调.cmd`。
   若后台已启动且未加载最新程序，先双击同目录 `停止网页联调.cmd` 再启动。
3. CH5 拨到最上（约 1000），右摇杆回中。给 STM32/接收器低压供电，
   下载本页指定的新 HEX 并复位。从启动窗口的 `http://127.0.0.1:18080/`
   进入网页，Ctrl+F5 刷新，打开“底盘监视”，保持实时模式。
   不直接打开本地 index.html。
4. 等 MQTT SESSION 双向握手和新心跳完成后，应看到 STM32 在线、**mqttmotor60**、
   **“底盘架空实测 · 电机输出已启用”**；
   页面明确显示 **最高 60% PWM**；
   CH1/CH2 约 1500、CH5 约 1000、输入有效，
   状态“等待解锁”，左右输出 0。未解锁时电机不应转。
5. 在上述锁定条件下接通 D60A 功率电源。电机仍应停止。
   如果此时持续转动，立即切断功率电源，排查驱动器端子和方向/PWM 线。
6. 右摇杆回中、CH5 最上保持 1–2 秒，再把 CH5 拨到最下（约 2000）。
   网页变成“就绪”，摇杆仍回中时输出仍为 0。
   如果不足 1 秒就提前拨到最下，不会在高档等待后自动解锁；
   需重新拨回最上、右摇杆回中保持 1–2 秒，再拨到最下。
7. **先小幅向上推右摇杆，短点动后回中**。已接左电机应按底盘前进方向转动，
   松杆后斜坡减到 0；再小幅向下验证反向。卡住只嗡响时不要长时间加油门。
   首次不直接满杆，不用突然大幅换向判断方向。
8. 推杆产生小输出时，把 CH5 拨回中间或最上。输出应立即归零、驱动器收到停止条件。
   网页约一秒后更新，机械停下还受惯性及负载影响。
9. 通过后断电，改为只接右电机验证相同步骤；两边各自通过后再断电接好 MA、MB。
   单电机阶段网页仍可能显示两侧指令，这是因为算法同时计算两路，未接电机的一侧不会运动。
10. 两侧都接好，按相同的回中、低档保持、高档解锁流程，验证以下动作。

| 右摇杆 | 两侧应有的动作 | 满杆稳定后的网页输出（近似值） |
| --- | --- | --- |
| 向上 | 两侧都按车辆前进方向转 | 左 +60%、右 +60% |
| 向下 | 两侧都按车辆后退方向转 | 左 −60%、右 −60% |
| 向左 | 左侧后退、右侧前进，向左原地转 | 左 −60%、右 +60% |
| 向右 | 左侧前进、右侧后退，向右原地转 | 左 +60%、右 −60% |
| 回中 | 两路逐步归零、停止 | 0%、0% |
| CH5 回中/上档 | 锁定，立即给出停止条件 | 0%、0% |

先小幅验证，确认正常再逐步加大幅度。脉宽端点若是 1995 而非 2000，
略低于 60% 的小差别正常。百分比是控制指令，不是编码器测得的实际速度。
中位 1500 ±50 µs 为死区，输出为 0；离开死区后，摇杆偏移越大，目标输出越大。
60% 版直行时约 1775 µs 对应 +30%，2000 µs 对应 +60%，1225 µs 对应 −30%。
右摇杆前后与左右同时偏移时进行差速混控、同比例限幅，不会超过当前固件上限。

## 4. 方向相反与失控保护

- 如果一侧电机前进方向相反：先切断功率电源和低压电源，
  只交换该侧电机的两根功率线，再从锁定、小幅点动开始验证。
  不要因为电机安装朝向相反就交换 CH1/CH2 或 A1/A2 信号线。
- 软件也预留 `Inc/motor_web.h` 中的左右反向选项，修改后要重新编译；
  首次按电机线极性统一车辆前进方向，再用小输出核验。
- 架空、小输出条件下关闭发射机进行失控检查，准备随时切断电机功率电源。
  接收器如果停止有效 PWM，本地控制会在超过 100 ms 的输入超时后停车，
  网页显示失效；恢复信号后必须先回到锁定档重新解锁。
- 接收器如果保持最后一次有效 PWM，STM32 无法仅靠 PWM 判断无线断联。
  如果关闭遥控器后仍保持运动，立即断电，设置接收器失控输出：
  CH5 低于 1700、CH1/CH2 回中，实际验证后才继续。先只读观察失控行为也可以。
- 此阶段只做架空验证。失控停车和硬件断电停止未验证通过，不进入落地测试。

## 5. 控制与网页的关系

- 电机控制由 SysTick 每 10 ms 执行；网络连接、AT 等待和网页刷新不控制电机。
- Wi-Fi 已连接不能证明在线。后台先发布 `SESSION:<32位小写随机值>`，
  STM32 新心跳回传 token 后才完成 MQTT 双向握手，API 的证据为 `mqttVerified=true`。
  在线还要求 broker 正常、最新有效心跳年龄不超过 5 秒（age <= 5s）；
  retained、重复和倒序心跳不刷新在线证据，超时隐藏旧读数。
- AT+MQTTPUBRAW 异步等待提示符后发送精确长度数据，再等待发布结果。
  普通 OK 或 busy 不确认发布，超时/断线时隔离迟到响应、恢复串口同步后重新连接；
  不再通过 STM32 HTTP /probe 请求取 token，也不开底盘 HTTP 服务器。
- 电脑热点或 MQTT 断开时，网页会离线，但遥控器本地控制继续工作。
  **断 WiFi 不是停车方法**；用 CH5 锁定或直接切断驱动器功率电源。
- 实际电机三档上限分别为 300‰/600‰/1000‰（30%/60%/100%），RC 模拟上限为 300‰。
  每 10 ms 改变 10‰，从零到三档上限约需 0.3/0.6/1 秒；摇杆逐步偏移时跟随目标变化。
  换向先降到零，保持至少 50 ms，再反向。
  停顿期间短暂回中或改变方向不会取消停顿；回中减到零后也保留这段零输出间隔。
  回中是斜坡减速；CH5 锁定或有效 PWM 超时是立即关闭输出。
- 独立看门狗仅由控制中断刷新；故障处理先禁用 PWM、拉低方向输入。
  看门狗复位后重新锁定，不会自动恢复运动。
- 不初始化 LCD/FSMC。PF10 仍归网络 LED 自检使用，不用它判断是否解锁。

## 6. 软件验证与产物

`Tools/make_motor_project.ps1` 从 RC 工程派生电机目标，
保留 ST-Link/SWD、芯片和 Flash 算法配置，输出到独立 `Objects_Motor_Web`。

编译只生成固件，不向板子写入，也不通过网络执行运动。

```powershell
$env:F407_PROTOCOL_TARGET = 'board_chassis_web_f407_60pct'
python -X utf8 firmware/board_web_link_test_f407/Tools/test_motor_web.py
python -X utf8 firmware/board_web_link_test_f407/Tools/test_protocol.py

python -X utf8 firmware/board_web_link_test_f407/Tools/test_mqtt_bridge.py
Remove-Item Env:F407_PROTOCOL_TARGET
```

切换 30%/100% 时先编译对应工程，再将 `F407_PROTOCOL_TARGET` 改为该目标，
运行 `test_motor_web.py` 和 `test_protocol.py`。恢复与桥接测试目前使用 60% 目标，
运行它们前先编译 60% 工程，并将环境变量改回 `board_chassis_web_f407_60pct`。
寄存器、协议、恢复和隔离 MQTT/API 测试只证明软件行为，
不证明实际电机、驱动器、接线、失控保护或机械制动性能通过。
