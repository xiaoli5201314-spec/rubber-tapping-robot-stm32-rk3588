# HT-10A / F-10A 遥控桌面联调

本版用于电机驱动未到货时，验证接收器、STM32 和原有 4.3 寸竖屏。**只显示模拟行驶指令，不驱动电机；测试期间不要接电机驱动和切割装置。**

## 工程与下载文件

- Keil 工程：`.\firmware\chassis_f407\MDK-ARM\rc_bench_f407.uvprojx`
- 编译输出：`.\firmware\chassis_f407\MDK-ARM\Objects_RC_Bench\rc_bench_f407.hex`
- 编译日志：`.\firmware\chassis_f407\MDK-ARM\rc_bench_build.log`
- 测试目标名：`rc_bench_f407`，编译宏 `RC_BENCH_TEST=1`。

原 `chassis_f407.uvprojx` 正常底盘工程仍保留。此次烧录必须选择测试工程，不能混用两个 HEX。用 Keil 打开测试工程，确认 ST-Link/SWD 设置，再编译和 Download；烧录后复位。此次代码准备不包含自动烧录或实物验证。

两个目标共用输入、安全状态机、混控、斜坡和显示源码。测试目标不初始化/启动 TIM4 PWM；电机控制口 PB6/PB7、PD6/PD7、PE5/PE6 在正常初始化后保持推挽低电平，进入错误处理时也会强制这六脚为低电平。复位期间仍不能把软件当作硬件急停。

## 断电接线

| F-10A 接收器 | STM32 端 | 用途 |
| --- | --- | --- |
| CH1 的 S / SIG | PB10 | 右摇杆左右、转向 |
| CH2 的 S / SIG | PB11 | 右摇杆上下、前后 |
| CH5 的 S / SIG | PF6 | SWA 三段开关 |
| 通道排针的 + / VCC | 稳定 5 V | 接收器供电 |
| 通道排针的 - / GND | 开发板 GND | 共地 |

只需一组接收器供电线。按实物 `S / + / -` 丝印判断，不能凭照片方向或线色猜。**5 V 接电源端，不接 GPIO；左侧 EXT-V 是电压回传接口，本测试不使用。**

**输入电平与下拉：**接收器手册未明确 PWM 高电平，按可能是 5 V 处理。PB10/PB11/PF6 都是 FT 引脚，本固件将其设为数字定时器输入、`GPIO_NOPULL`；ST 数据手册第 78 页要求输入高于 `VDD+0.3 V` 时关闭内部上下拉。因此不能继续依赖内部下拉。建议在 MCU 侧 **PB10、PB11、PF6 各接一个约 10 kΩ 电阻到 GND**，为信号断开提供明确低电平。若暂时没加外部下拉，可先测接收器正常连接时的数据，但不要用拔线测试证明失效保护，因为悬空输入可能拾取干扰。外部下拉不是电平转换，不能据此接入高于允许范围的信号。

若使用正点原子探索者 V3 原开发板：

- 直接飞线到 PB10/PB11 时，拔掉 P2 中连接这两脚的跳帽，避免 RS232/ATK-MODULE 外设占用。
- PF6 还连接 ATK-MODULE 的 KEY 脚；该接口不要插模块，不要同时连接其它 KEY 电路。P2 不在 PF6 这条线上。
- 本程序把三根输入脚配置为定时器数字输入，不使用 ADC。ST 引脚表标为 FT，但接收器供电范围不代表信号电平范围；接收器本次只用 5 V 供电，改线前断电，避免接收器上电而 MCU 未供电。

自绘板按 PB10/PB11/PF6 对应网络接线，不套用原开发板的 P2 说明。屏幕驱动沿用此前已使用的原板屏幕配置。

## 遥控器操作

第一次配对：

1. 先关闭发射机，给接收器和开发板正确供电；接收器 LED 慢闪表示未连接。
2. 长按接收器 `BIND` 约 1 秒，LED 快闪表示进入配对。
3. 打开 HT-10A 发射机；LED 常亮表示配对成功。
4. 配对成功后通常下次自动连接，无需每次按 BIND。

在遥控器主界面按确认键，进入“智能设备 → 舵机设置”，设置 **50 Hz、180°**。混控、微调、行程、通道映射、正反先保持默认。本固件接受有效脉宽 800–2200 µs、周期 15–25 ms；正常模拟舵机输出约 1000–2000 µs、20 ms。330 Hz 模式不适用。

## 屏幕验收顺序

屏幕标题为“遥控联调”，有“电机禁用”“左模拟/右模拟”。每 200 ms 更新一次：

- 三路脉宽（µs）、最后有效 PWM 周期（ms）、OK/--。
- 锁定/等待/就绪/失效状态。
- 左右目标（千分比，`+300 /1000` 即 +30%）与模拟方向、模拟 PWM 百分比；**不是实测电机速度，也不是实际输出占空比。**
- 各通道输入故障。

操作：

1. **先看输入，不急着解锁。**右摇杆居中，CH1/CH2 应约 1500 µs、周期约 20.0 ms，三路为 OK。
2. 摇杆左右动，CH1 改变；上下动，CH2 改变。分别拨动 SWA 三档，确认 CH5 约 1000/1500/2000 µs。
3. SWA 选 CH5 小于 1700 µs 的档位，右摇杆居中保持至少 1 秒；再拨到 CH5 ≥1700 µs 的档位，状态进入“就绪”，绿灯亮。
4. 再推动右摇杆，观察左右模拟目标、方向、百分比变化。默认上限 30%，有斜坡和换向等待。若推上却显示后退，记录 CH2 数值，后续调整油门极性，先不要乱改映射。
5. SWA 拨回低档，模拟输出归零；首次确认这一项。
6. **关闭发射机测试无线失联行为。**观察三路是否消失、回中还是保持。若接收器仍输出合法 PWM，程序可能仍显示 OK/就绪，不能将“关机”当作可靠急停。
7. **先装好各路外部下拉，再测试断开 CH1/CH2/CH5 信号线。**若先处于就绪，最后有效 PWM 超过 100 ms 后退出就绪；屏幕下一次刷新显示“失效”、缺失通道为 `---- / --.-ms / --`，模拟输出归零。改变接线先断电；要验证运行中的断线反应，可在断电时预先安装只断信号的开关，再上电、解锁后操作开关。
8. 恢复信号后，SWA 先回低档、摇杆居中，再重新解锁，不允许自动恢复行驶。

**100 ms 检查的是有效 PWM 是否持续到达，不是接收器无线连接状态。**接电机前，必须单独验证接收器失控保护、硬件急停以及实际输出；桌面测试不能替代这些检查。

## 没有信号时

- 三路都是 `----`：先查接收器 LED、共地、50 Hz 模式、接收器是否为 PWM 版本。
- CH1/CH2 不变：查 S 行是否接对、PB10/PB11 和 P2/串口复用。
- 只有 CH5 不变：查 PF6、ATK-MODULE KEY 复用和 SWA 默认映射。
- 输入正常却无法解锁：查 CH1/CH2 是否在 1450–1550 µs 内、是否先回 SWA 低档，再居中等待 1 秒。
- 完全没接接收器：仍应显示界面，保持锁定，三路 `----`，模拟输出为零。
